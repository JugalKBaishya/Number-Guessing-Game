# Number Guessing Game 🎮

My first game developed using C programming.

## About the Project

This is a simple number guessing game where the computer generates a random number between 1 and 100. The player tries to guess the correct number.

### How to Play
- Enter a number between 1 and 100.
- If your guess is too high, the game asks you to enter a lower number.
- If your guess is too low, the game asks you to enter a higher number.
- Keep guessing until you find the correct number!

The game displays the total number of attempts at the end.

## Technologies Used
- C Programming
- Standard C Libraries

## How to Run

Compile the program:

```bash
gcc first_game.c -o game
```

Run on Windows:

```bash
game.exe
```

Run on Linux:

```bash
./game
```

- Conditional statements
- Do-while loops
